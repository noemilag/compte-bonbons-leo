# Le butin hanté de Léo 🎃

Le bilan de la récolte de bonbons d'Halloween 2026 de Léo, en chiffres et en graphiques animés.

- `index.html` : la page complète (données intégrées, graphiques faits avec [d3](https://d3js.org)).
- `data/recolte-leo-2026.csv` : le décompte de Léo, une ligne par sorte de bonbon.
- `data/soiree-halloween-2026.csv` : les heures de marche et les sacs donnés à la porte.

Pour mettre à jour les chiffres, modifie les données dans le bloc `const raw = { … }` au début de `index.html`.
